# Ask a Doctor — Online Healthcare Consultation Platform

## 📖 Project Overview
**Ask a Doctor** (*Your Health, Our Priority*) is our final JavaScript group project developed using **HTML5**, **CSS3**, and **JavaScript (ES6+)**. The goal of this web application is to make healthcare information and online medical consultations easy to access, understand, and navigate through a clean, interactive, and responsive interface.

🔗 **Live Demo:** [https://yosofimarwa24-lang.github.io/Ask-a-Doctor/](https://yosofimarwa24-lang.github.io/Ask-a-Doctor/)

---

## ✨ Key Features
- **Appointment Booking System:** Users can select a medical specialty, choose an available doctor, pick a preferred date and time slot, and submit their health concern.
- **Dynamic Doctor Filtering:** Selecting a medical specialty dynamically updates the list of available doctors in the booking form.
- **Form Validation:** Real-time validation on the appointment and newsletter subscription forms to ensure accurate user inputs.
- **Interactive FAQ Accordion:** Expandable and collapsible frequently asked questions for smooth user navigation.
- **Responsive Design:** Fully optimized layout for desktop, tablet, and mobile devices.

---

## 💻 JavaScript Concepts Implemented
To fulfill the core technical requirements, the following JavaScript concepts have been applied in `script.js`:
- **Variables & Data Types:** Organized data storage using `const` and `let`.
- **Conditions (`if/else`, `switch`):** Handling specialty selection logic, form checks, and user interactions.
- **Loops (`for`, `while`):** Iterating through doctors, specialties, and FAQ items.
- **Functions:** Modular, reusable functions for booking, filtering, and UI updates.
- **Arrays & Objects:** Storing structured data for doctors, specialties, time slots, and patient stories.
- **Array Methods (`.map()`, `.filter()`, `.forEach()`, `.push()`):** Filtering doctors by specialty and rendering dynamic options.
- **DOM Manipulation:** Updating dropdown options, toggling FAQ answers, and displaying confirmation messages dynamically.
- **Event Listeners:** Handling clicks, form submissions (`submit`), and dropdown changes (`change`).
- **Form Validation:** Checking required fields (Full Name, Email Address, Specialty, Doctor, Date, and Time) before submission.
